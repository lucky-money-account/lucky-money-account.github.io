# 分层 VAE（HVAE）· 知识点与实验记录

> 站 A2。目标：理解**多层 ELBO**，实现最小 2 层 VAE。
> 代码：`Generative AI/VAE/Double_Layer_VAE.ipynb`

## 1. 结构（本版）

```
编码：x → enc1 → q(z1|x) → z1 → enc2 → q(z2|z1) → z2
生成：z2 ~ N(0, I) → dec2 → p(z1|z2) → dec1 → x̂
```

马尔可夫链：**每个潜变量只依赖相邻**（这是 HVAE 的 M）。

## 2. 损失（多层 ELBO）

- **重构**：`E_q[log p(x|z1)]` → 高斯似然 → MSE；
- **kl1** = `KL(q(z1|x) ‖ p(z1|z2))` —— 层间一致性（让 dec2 预测的 z1 分布对齐编码器）；
- **kl2** = `KL(q(z2|z1) ‖ N(0,I))` —— 顶层先验；
- `total = recon + β·(kl1 + kl2)`，本实验 β=0.1。

对比单层 VAE：**每多一层，就多一组"条件分布 + 一个 KL"**。

## 3. 与扩散的关系（本站在路线里的意义）

把**层数 T 推大**、并把"编码器"**固定成高斯加噪**（不学参数）→ 就得到 **DDPM**。

> **扩散 = 编码器固定的分层 VAE。** 前向加噪 = 编码器；反向去噪 = 解码器。

## 4. 实验记录（实测：lr=1e-4，β=0.1，256×256，眼镜人脸）

| epoch | 重构 MSE | 重构 std | 生成 std | 重构色彩强度 | 输入色彩强度 |
|---|---|---|---|---|---|
| 2 | 0.010 | — | — | 28.0 | 43.2 |
| 4 | 0.0063 | 0.211 | 0.072 | — | (输入 std 0.208) |

- **重构**：结构还原良好（重构 std ≈ 输入 std），**颜色保留但偏淡**（VAE 均值效应，正常）；
- **生成**（从先验 z2 采样）：std 仅 0.07 → 一片平灰；顶层 **posterior collapse**。

## 5. 结论

1. **机制跑通**：多层 ELBO 正常工作（loss 稳定下降、无 NaN、重构≈原图）；
2. **生成弱** 是分层 VAE 的**固有难点**（顶层塌缩），叠加"潜变量几乎没压缩"——`z1` 约 13 万维、原图 19.6 万维，几乎没有瓶颈 → 模型更像个自编码器；
3. 想要好的生成 → 交给后面 **VQ-VAE / Diffusion** 那一支。

## 6. 踩过的坑（最小改动修复）

- `plot_epoch`：`dec2` 返回 `(mu, logvar)` **元组**，不能直接喂 `dec1` → 取 `mu`；
- 生成采样的 `z2` 形状要对齐训练（256 输入 → `32×32`）；
- 推理要 `model.eval()`（解码器里有 BN）；
- `lr=1e-3` 太大 → 改 **`1e-4`**；
- `logvar` 加 `torch.clamp(-10, 10)` 防 `exp` 溢出成 NaN。
