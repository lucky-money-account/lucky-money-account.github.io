发布中心

把 Markdown 笔记拖进来，页面会用与文章页完全相同的渲染器预览公式 / 表格 / 代码，然后经 GitHub API 提交到博客仓库。仓库提交后 GitHub Pages 会自动重新构建（通常 1–2 分钟），文章即可在博客里打开。

GITHUB 配置

目标仓库：（分支 main）
· 需要新建一个 Fine-grained Token， Repository access 只选 lucky-money-account.github.io，权限勾选 Contents → Read and write 即可，其它权限全不选。
· Token 只保存在你自己浏览器的 localStorage，不会提交进仓库；此页面公开但别人没有你的 Token，无法写入。
· 没有 Token 也没关系：下方仍可「下载 Markdown / posts.json」，按第 3 节手动提交。

手动发布（无 Token）

1. 拖入 Markdown，填好标题 / Slug / 摘要 / 标签，点「下载 Markdown」得到 <slug>.md；
2. 把文件放到仓库的 blog/posts/ 目录（可通过 GitHub 网页 Upload files 直接拖拽上传）；
3. 若文章带图片：点「下载关联图片」，把图片放到 blog/assets/<slug>/ 目录（文件名与下载时一致），Markdown 里用 assets/<slug>/<文件名> 引用；
4. 点「下载 posts.json」，用它替换仓库里的 blog/posts.json（或手动在 JSON 的 posts 数组里加一条记录）；
5. 提交后等待 GitHub Pages 重新构建，刷新 文章列表 即可看到。
